Hello programmer, it is a pleasure that you want to contribute to PyTXT!! To see more about the project, see the PyTXT readme.

# Report a bug

- Go to the issues tab in the GitHub repository
- Click in "New issue"
- Describe the bug in a detailed way, and step by step how it happens

# Suggesting new ideas

New ideas are always welcome on PyTXT. If you want to suggest one, create an issue in this repo and describe the idea that you want to suggest and why it would be useful.

# How to run the code locally

- Install Python (if you don't have it installed, even though you probably have it in your PC)
- Clone this repository on your computer
- Install the required Python libraries (if you don't have them installed, for now it is only PyQt5 "pip install pyqt5")
- Execute the main python file to test your changes

And I guess that's it, have fun contributing to PyTXT!
