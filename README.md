# PyTXT
PyTXT is a text editor which is made in Python and PyQt5 that was made to improve my Python skills, It's a recreation of the Windows Notepad, and it does almost everything Notepad does

With PyTXT ou can:

- Type

- Save as .txt or all files

- Open .txt or all files

- Undo

- Redo

- Copy all

- Select all

- Change font

- Change font size

..and that's pretty much it! Please tell me what I can improve so better versions are created, this is only the first version
